# Legacy Notebooks

These notebooks are retained as historical material from the original repository.

## Classical machine learning

The notebooks under `classical/` cover material that remains aligned with the
modern project scope. Their useful ideas will be migrated incrementally into typed,
tested package implementations and compact maintained examples.

## Optimization

The AdaGrad notebook is retained under `optimization/` as background material for
the numerical-foundations phase.

## Out of scope

The modern repository is intentionally narrower than the original notebook
collection.

- `out-of-scope/time-series/` contains ARIMA/SARIMA material and its stock-market
  dataset. Time-series forecasting belongs in dedicated forecasting repositories.
- `out-of-scope/deep-learning/` contains the RNN/LSTM/GRU notebook. Deep learning
  is not part of this repository's current first-principles classical-ML scope.

These files are preserved for provenance, not maintained as supported examples.

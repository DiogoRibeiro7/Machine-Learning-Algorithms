## Example policy

A maintained example should:

- be deterministic where randomness is involved;
- illustrate one algorithm or numerical idea;
- remain compact enough to review;
- use the public package API;
- avoid duplicating implementation logic;
- avoid becoming the only documentation of an important behavior.

Historical notebooks remain available under `notebooks/legacy/`, but they are not maintained against the modern package API.
